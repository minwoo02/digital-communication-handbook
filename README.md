# Digital Communication Handbook

디지털 통신과 신호 시스템의 개념을 연결해 읽는 학습 문서이다.

**[문서 사이트](https://minwoo02.github.io/digital-communication-handbook/)** · [학습 로드맵](docs/roadmap.md)

## 다루는 내용

- 통신 시스템의 전체 구조와 정보의 디지털 변환
- 디지털 변조·신호공간·I/Q·QPSK 송수신
- 무선 채널·Fading·잡음·BER·Shannon Capacity
- 채널 코딩·에러 제어·다중 접속·대역확산
- 하드웨어 설계와 Bio/Implant Communication

주제별 목차와 전체 학습 순서를 함께 제공한다. 개념지도에서 관련 문서로 바로 이동할 수 있다.

문서 작성과 관리 방법은 [CONTRIBUTING.md](CONTRIBUTING.md)에 정리한다.
