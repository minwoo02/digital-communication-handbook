# Synchronization (동기화)

## 블록도에서의 위치

동기화는 21개 직렬 블록 뒤에 붙는 별도 단계가 아니라 송신기와 수신기 전반에 걸친 공통 과정이다. 타이밍·주파수·위상의 기준을 맞추는 관점으로 읽는다.
