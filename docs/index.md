# Digital Communication Handbook

디지털 통신의 전체 흐름부터 신호 표현, 변조, 채널, 오류 제어, 다중 접속과 하드웨어 응용까지 연결해 읽는 학습 자료이다.

[학습 로드맵과 개념지도](roadmap.md)

## Theory

- [Foundations](theory/foundations/index.md): 통신 시스템의 구조와 정보의 디지털 변환
- [Modulation & Signal Space](theory/modulation/index.md): Bit·Symbol·Constellation, 대역통과 변조, I/Q, QPSK와 수신기
- [Channel & Performance](theory/channel/index.md): 무선 채널, Fading, 잡음, BER와 Shannon Capacity
- [Coding & Error Control](theory/coding/index.md): Block Coding, Hamming Code, Syndrome와 Convolution Coding
- [Multiple Access & Spread Spectrum](theory/multiple-access/index.md): 다중화, 다중 접속과 대역확산

## 읽는 방법

왼쪽 목차에서 주제를 선택하고, 오른쪽 목차에서 글 안의 세부 항목으로 이동한다. 각 글 아래의 이전·다음 링크는 전체 학습 순서를 따른다. 개념지도의 항목을 누르면 관련 문서로 이동한다.
